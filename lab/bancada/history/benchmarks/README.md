# Evidências históricas da bancada

Esta pasta reúne somente entradas, fixtures e resultados ainda citados por contratos,
testes, passos, laudos ou sínteses atuais do Bateia. Os diretórios numerados identificam
o passo que produziu a evidência; não constituem uma suíte cumulativa de certificação.

Arquivos internos podem registrar caminhos válidos no commit de origem. Eles não devem
ser reescritos para aparentar que foram produzidos pela árvore atual.

Novas execuções descartáveis, compilações e mutantes são produzidos em `/dev/shm`.
Somente o menor artefato necessário para reproduzir ou explicar uma obrigação atual
pode ser promovido para este histórico.
