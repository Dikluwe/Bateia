# Regressões do validador JSON

Cobrir um valor, arrays/objetos independentes, número com expoente grande,
delimitadores dentro de strings, limite exato de profundidade, excesso de
bytes/tokens, entrada inválida/truncada, UTF-8 inválido e campos duplicados.
Incluir aliases ASCII, escapes, Kelvin e sigma/final-sigma Unicode. Fuzz seeds
devem garantir que toda entrada aceita também é JSON válido.
