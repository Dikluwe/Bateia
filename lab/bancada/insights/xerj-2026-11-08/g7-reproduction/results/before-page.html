One line, no clone and no index: xerj hub pull mini-g7 fetches this corpus’s signed, pre-indexed pack and checks its SHA-256 and signature before restoring it. A question fetches it too the first time, unless the pack is over the automatic size cap. The answer names the corpus, its pin date and its licence. Use --def for an exact value, signature or default. Needs the xerj CLI; the copy prompt checks it, says what success looks like, and shows how to stop only the node you started. No shell: the MCP tool xerj_hub_ask with corpus: "mini-g7", once the pack is on the machine (a tool never downloads one). Not sure this is the right corpus?
