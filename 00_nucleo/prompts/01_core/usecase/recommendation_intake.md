# Prompt — Recommendation Intake Use Cases

Implemente as regras puras do passo 0083. Materialize defaults versionados com
proveniência, preserve valores explícitos falsos, zero e vazios, emita perguntas apenas
para necessidades humanas tipadas, valide respostas confirmadas pela autoridade correta
e gere um novo hash sem mutar evidência. Converta causas de inconclusão em resolvers
determinísticos; computação e coleta nunca devem ser disfarçadas como perguntas à IA.
Preserve proveniência de qualidades e condições operacionais declaradas pelo usuário.
