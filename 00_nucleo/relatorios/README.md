# Relatórios e Laudos Arquiteturais ($L_0$ — Núcleo)

Esta pasta armazena os **Relatórios de Análise Arquitetural** gerados pelo motor de busca Bateia.

---

## Propósito

Em conformidade com a Arquitetura Cristalina Tekt (v1.4), os relatórios gerados a partir do funil de busca representam artefatos do núcleo ($L_0$), servindo como registros históricos de decisões, mapeamentos de dependências e referências de soluções de código auditadas.

---

## Estrutura de Arquivos

Cada relatório salvo nesta pasta segue o formato:
- `relatorio_<query>_<data>.md`

Exemplo de relatório compilado:
- `relatorio_fiber_tekt.md`
