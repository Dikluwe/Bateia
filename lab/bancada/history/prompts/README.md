# Prompts históricos supersedidos

Este diretório preserva, sem reescrita, prompts que governaram materializações
anteriores mas foram supersedidos por uma decisão arquitetural explícita.

Os prompts `04_wiring/durable_config*.md` descrevem a implementação anterior ao passo
0077. A obrigação atual está em `00_nucleo/prompts/03_infra/durableconfig/`.

Os prompts dos oráculos `market_discovery_step0027` e
`improvement_synthesis_step0028` congelaram a construção concreta do runtime em
L4. O passo 0079 substitui essa observação de localização por testes funcionais do
container L3.
