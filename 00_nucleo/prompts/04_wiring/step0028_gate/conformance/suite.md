# Prompt espelhado — executor de conformidade O2/O3

Decodifique o corpus protegido com JSON estrito, schema e hash contratual congelados. Rejeite IDs ausentes ou duplicados e exija representação das doze obrigações públicas e das operações O3 ampliadas. Execute cada caso por um `Subject` injetado e compare a observação integralmente, classificando divergência como `Violated` e igualdade como `Preserved`, em ordem determinística.

Não contenha adaptadores para código candidato nem leia expectativas de ataques.
