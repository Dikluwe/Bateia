# Desejos do Bateia

Este diretório registra **desejos de produto**: resultados que gostaríamos que o
Bateia produzisse, antes de decidir arquitetura, versão, prazo ou implementação.

Um desejo não é uma ADR, requisito aprovado ou item automaticamente incluído no
roadmap. Ele preserva a intenção e os critérios de valor para que uma solução
futura não implemente apenas a mecânica e perca o problema original.

Estados possíveis:

- `DESEJO`: intenção registrada, ainda sem compromisso de implementação;
- `EM_EXPERIMENTO`: há uma hipótese sendo medida na Arena;
- `PROMOVIDO`: partes do desejo viraram especificação, prompt ou ADR;
- `DESCARTADO`: evidência mostrou que o desejo não deve ser perseguido.
