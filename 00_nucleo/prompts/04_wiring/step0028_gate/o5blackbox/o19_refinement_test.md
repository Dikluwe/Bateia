# Prompt — O19 sanitized projection self-tests

Leia a projeção pública sanitizada O18 como entrada contratual e transforme cada
um de seus sete documentos canônicos em exchange ARTIFACT_READ. Exija `Unknown`
para todos. Para cada projeção, remova exatamente um campo estrutural obrigatório
e exija `Preserved`. Verifique precedência de violação, JSON estrito e manifesto.
Não use identidade de caso, hashes de ataque, marker, expected, texto humano,
candidato nem artefato reservado.
