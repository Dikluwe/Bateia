# Contratos da releitura técnica

Usar provedor simulado para validar commit fixado, bytes relidos, digest
divergente, revisões erradas, stale, arquivos ausentes/duplicados/inesperados,
licença raiz alternativa, falhas e limites. Achados vencidos, contraditos ou
não suportados não devem fazer consultas. Alvos locais, SHA abreviado e
candidatos duplicados são rejeitados antes da leitura; respeitar cancelamento.
