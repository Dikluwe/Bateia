# Prompt — O15 oracle refinement self-tests

Materialize self-tests documentais para a revisão O15 do oráculo segregado do
Passo 0028. Cubra as relações públicas O02–O10 do protocolo O8 usando somente
estruturas de contrato: witness técnico `PARTIAL` abaixo do mínimo; target
`UNKNOWN` com evidência de baseline ausente; composição não medida; licença
`UNRECOGNIZED` com transfer/status incapaz; counterevidence
`BUDGET_EXHAUSTED`; e códigos controlados de gap para identidade, provider,
utility e security. Demonstre que `PATTERN_ADAPTATION`, `REFERENCE_ONLY`, texto
livre e documentary-only `PARTIAL` não são proxies de opacidade. Demonstre
precedência de violação e JSON público estrito. Não use IDs de caso, hashes de
ataque, markers, expected, candidato, records/configs nem artefatos reservados.
