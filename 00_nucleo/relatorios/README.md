# Relatórios e Laudos Arquiteturais ($L_0$ — Núcleo)

Esta pasta reúne relatórios gerados e diagnósticos de engenharia do Bateia. São registros históricos: títulos e conclusões antigos não constituem garantias da versão atual.

---

## Propósito

Em conformidade com a Arquitetura Cristalina Tekt (v1.4), os relatórios gerados a partir do funil de busca representam artefatos do núcleo ($L_0$), servindo como registros históricos de decisões, mapeamentos de dependências e referências de candidatos examinados no escopo declarado. Encontrar um arquivo não equivale a validar uma solução.

---

## Estrutura de Arquivos

Cada relatório salvo nesta pasta segue o formato:
- `relatorio_<query>_<data>.md`

Exemplo de relatório compilado:
- `relatorio_fiber_tekt.md`
