# 0101 — CLI de progresso consultivo

Testar trace review sem registros e com recibo completo, stdout/disco iguais,
hashes vinculados, decisão preservada e entrada imutável. Recusar JSON ambíguo,
campos desconhecidos, esquemas/hash adulterados e conclusão sem referência,
sem stdout ou sobrescrever saída pré-existente. Proteger aliases/hardlinks,
links simbólicos e FIFO usando admissão/writer trace compartilhados.
