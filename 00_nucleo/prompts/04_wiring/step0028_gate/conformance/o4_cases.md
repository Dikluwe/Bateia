# Prompt espelhado — casos executáveis O4 do Passo 0028

Materialize casos públicos independentes e determinísticos para cada commitment O4. Cada caso negativo deve chegar à porta indicada com entrada válida e expectativa normativa congelada, antes de qualquer desvio semântico. Os 12 positivos reutilizam controles de referência congelados; os dez opacos carregam uma razão de opacidade explícita e só admitem `Unknown`. Não consulte implementação candidata nem casos adversariais.
